四大核心功能模块的详细设计

🤖 OCR 模块 - 智能识别流程

采用本地 + 云端混合方案，优先使用本地 PaddleOCR，失败时自动降级到云端阿里云 OCR

flowchart TD A[📷 用户上传图片] --> B{本地 PaddleOCR 识别} B -->|成功| C[📝 解析识别结果] B -->|失败| D{云端 OCR 降级} D -->|成功| C D -->|失败| E[❌ 返回错误信息] C --> F[🔍 提取关键信息] F --> G[💰 金额] F --> H[📅 日期] F --> I[🏪 商户] F --> J[🏷️ 类别] G --> K[🖥️ 展示识别结果] H --> K I --> K J --> K K --> L{用户确认} L -->|编辑| M[✏️ 用户修改信息] M --> N{再次确认} N -->|确认| O[💾 保存记录] N -->|取消| P[❎ 取消操作] L -->|直接确认| O O --> Q[📊 更新账户余额] Q --> R[✅ 记录完成] style E fill:#ff6b6b,color:#fff style P fill:#feca57,color:#333 style R fill:#51cf66,color:#fff

核心接口定义

interface OcrResult {
  amount?: number;      // 识别到的金额
  date?: string;        // 识别到的日期
  merchant?: string;    // 识别到的商户
  category?: string;    // 推荐分类
  rawText: string;      // 原始识别文本
  confidence: number;   // 识别置信度
}

预算计算公式

📊
预算进度
已消费 / 预算 × 100%
💰
剩余预算
预算 - 已消费
⚠️
超支金额
已消费 - 预算 (若 > 0)
