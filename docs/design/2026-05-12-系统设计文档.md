## 1. 技术架构

### 1.1 技术栈选型

| 层级         | 技术选型                  | 说明                                  |
|-------------|--------------------------|---------------------------------------|
| 桌面框架     | Electron                 | 跨平台桌面应用框架                      |
| 移动端       | Capacitor                | Android WebView 包装                   |
| 前端框架     | React 18 + TypeScript    | 类型安全的组件化开发                    |
| UI 组件库    | Ant Design 5             | 企业级 UI 组件库，内置响应式支持         |
| 状态管理     | Redux Toolkit            | 集中式状态管理                          |
| 本地数据库   | SQLite + better-sqlite3  | 轻量级本地数据库（Electron 生产模式）     |
| 开发数据层   | localStorage + Mock API  | Web/移动端开发模式数据持久化             |
| 测试框架     | Vitest + jsdom           | 单元测试（14 个用例）                   |
| OCR 引擎     | PaddleOCR（规划中）      | 开源本地 OCR                           |
| 云端 OCR     | 阿里云/腾讯云 OCR（规划中）| 云端 OCR API                          |
| 云端同步     | 飞书多维表格 API（规划中）| 数据云端存储与同步                      |

## 5. 核心模块设计

### 5.1 OCR 模块

#### 工作流程
1. 用户上传/粘贴截图
2. 优先尝试本地 PaddleOCR 识别
3. 本地失败时降级到云端 OCR
4. 解析识别结果，提取关键字段（金额、日期、商户、类别）
5. 展示识别结果给用户确认/编辑
6. 保存为记账记录

#### OCR 工作流程图

```mermaid
flowchart TD
    A[用户上传图片] --> B{本地OCR识别}
    B -->|成功| C[解析识别结果]
    B -->|失败| D{尝试云端OCR}
    D -->|成功| C
    D -->|失败| E[返回错误信息]
    
    C --> F[提取金额/日期/商户/类别]
    F --> G[展示识别结果]
    G --> H{用户确认}
    
    H -->|编辑| I[用户修改信息]
    I --> J{再次确认}
    J -->|确认| K[保存记录]
    J -->|取消| L[取消操作]
    
    H -->|直接确认| K
    K --> M[更新账户余额]
```

### 5.2 飞书同步模块

#### 数据映射
- 本地 records 表 <-> 飞书多维表格「消费记录」
- 本地 accounts 表 <-> 飞书多维表格「账户」
- 本地 categories 表 <-> 飞书多维表格「分类」

#### 同步策略
- 增量同步：基于 updated_at/synced_at 字段
- 冲突解决：以最后更新时间为准
- 手动触发 + 自动定时同步

### 5.3 预算模块

#### 预算计算流程

```mermaid
flowchart TD
    A[开始预算检查] --> B[获取当前周期预算]
    B --> C[查询该周期消费记录]
    C --> D[计算已消费金额]
    D --> E{判断超支状态}
    
    E -->|未超支| F[显示正常进度]
    E -->|接近预算 80%| G[显示警告状态]
    E -->|超支| H[显示超支警告]
    
    F --> I[更新UI显示]
    G --> I
    H --> I
    
    I --> J{超支检测}
    J -->|是| K[发送系统通知]
    J -->|否| L[正常显示]
    
    K --> M[记录警告日志]
    M --> N[结束]
    L --> N
    
    style H fill:#ff6b6b
    style K fill:#feca57
    style G fill:#feca57
```

#### 预算计算公式

```
预算进度 = (已消费金额 / 预算金额) × 100%
剩余预算 = 预算金额 - 已消费金额
超支金额 = 已消费金额 - 预算金额 (当已消费 > 预算时)
```

```mermaid
    participant DB as 本地数据库
    participant FS as 飞书API
    
    rect rgb(240, 255, 240)
        Note over U,FS: 手动同步流程
        U->>UI: 点击"同步到飞书"
        UI->>IPC: 调用同步接口
        IPC->>DB: 查询未同步记录
        DB-->>IPC: 返回变更数据
        IPC->>FS: 上传数据到飞书
        FS-->>IPC: 返回上传结果
        IPC->>DB: 更新同步时间戳
        DB-->>IPC: 更新完成
        IPC->>FS: 查询飞书变更
        FS-->>IPC: 返回云端数据
        IPC->>DB: 合并/更新本地数据
        DB-->>IPC: 合并完成
        IPC-->>UI: 返回同步结果
        UI->>U: 显示同步完成
    end
```
