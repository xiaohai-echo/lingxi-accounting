# 桌面端消费记账应用 - 需求说明书

**版本**：v1.0  
**创建日期**：2026-05-12  
**文档状态**：初稿

---

## 1. 项目概述

### 1.1 项目背景
开发一款桌面端消费记账应用，帮助用户便捷地记录、管理和分析个人消费行为，支持 AI 智能识别消费截图快捷记账。

### 1.2 项目目标
- 提供简单易用的记账功能
- 支持 AI 图片识别截图快捷记账
- 多账户管理
- 预算管理与提醒
- 数据统计与可视化
- 数据多平台数据同步

---

## 2. 功能需求

### 2.1 核心记账功能
- **收支记录管理
  - 添加/编辑/删除收支记录
  - 记录字段：金额、日期、类型（收入/支出）、分类、账户、标签、备注、附件
- **分类管理
  - 预设常用分类（餐饮、交通、购物、娱乐等）
  - 支持自定义分类

### 2.2 AI 快捷记账
- **图片识别
  - 支持图片上传或粘贴截图
  - 本地 OCR（PaddleOCR）+ 云端 OCR（阿里云/腾讯云）混合方案
  - 智能识别：金额、日期、商户、类别等信息
  - 可编辑识别结果后再保存

### 2.3 多账户管理
- 账户创建/编辑/删除
- 账户类型：现金、银行卡、微信、支付宝、信用卡等
- 账户余额管理与查看

### 2.4 预算管理
- 月度/季度/年度预算设置
- 按分类设置预算
- 预算进度可视化
- 超支提醒

### 2.5 数据统计与图表
- 收支趋势图
- 分类饼图/柱状图
- 账户余额变化图
- 自定义时间范围统计

### 2.6 数据导入导出
- **导入**：CSV、Excel
- **导出**：CSV、Excel、PDF、图片
- 飞书表格同步

### 2.7 飞书同步
- 与飞书多维表格双向同步
- 增量同步机制
- 冲突解决策略

### 2.8 数据安全
- 本地数据加密存储
- 密码保护
- 定期自动备份

---

## 3. 非功能需求

### 3.1 性能要求
- 应用启动时间 < 3 秒
- 记录查询响应时间 < 1 秒
- OCR 识别响应时间 < 5 秒（本地）/ < 10 秒（云端）

### 3.2 兼容性
- 支持 Windows 10/11
- 支持 macOS 10.15+
- 支持 Linux（Ubuntu 18.04+）

### 3.3 可用性
- 界面简洁美观，操作直观
- 提供操作指引

---

## 4. 技术约束

- 技术栈：Electron + React + TypeScript
- 本地数据库：SQLite
- OCR：PaddleOCR（本地）+ 阿里云/腾讯云 OCR（云端）
- 云端同步：飞书多维表格
